# ELNUR_EDU bot

ELNUR_EDU o'quv markazi uchun Telegram bot: davomat, vazifa, to'lovlar, qarzlar, coinlar.

Serverga o'rnatish (Ubuntu):

```
git clone https://github.com/matnazarovsarvar7-lang/elnuredu_markaz_bot.git /opt/elnur-bot
bash /opt/elnur-bot/install.sh
```

Token, parol va o'quvchilar ma'lumotlari bu repozitoriyda saqlanmaydi.
